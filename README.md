## 📌 Overview

This project is a professionally designed interactive Tableau Cheat Sheet covering the most important concepts frequently asked in:

- Tableau Developer Interviews
- Data Analyst Interviews
- BI Developer Interviews
- Dashboarding & Reporting Roles
- Analytics Consulting Roles

The goal of this project is to provide a **single, structured, interview-focused resource** that helps candidates revise Tableau concepts quickly and effectively.
